# Парсер Ozon на своём ноутбуке — установка

Работает на **Windows, macOS и Linux**. Нужен Python 3.9+.

## Шаг 1. Проверить Python

Открой терминал и введи:

- **Windows** (PowerShell или «Командная строка»): `python --version`
  Если не найден — поставь Python с https://python.org (при установке
  включи галочку **«Add Python to PATH»**).
- **macOS / Linux** (Terminal): `python3 --version`
  macOS: если нет — `brew install python`. Linux: `sudo apt install python3 python3-pip`.

## Шаг 2. Установить зависимости

Один раз выполни (браузер скачается автоматически, ~150 МБ):

**Windows:**
```
pip install playwright
playwright install chromium
```

**macOS / Linux:**
```
pip3 install playwright
python3 -m playwright install chromium
```

## Шаг 3. Добавить товары

Открой файл `ozon_products.txt` и вставь ссылки на товары Ozon — по одной
в строке. Строки, начинающиеся с `#`, игнорируются.

## Шаг 4. Запустить

Перейди в папку `price-parser` и запусти:

**Windows:**
```
python ozon.py
```
**macOS / Linux:**
```
python3 ozon.py
```

Можно проверить один товар без файла:
```
python ozon.py "https://www.ozon.ru/product/xxx-123456789/"
```

Откроется окно браузера, скрипт пройдёт по товарам, напечатает цены и
сохранит их в `ozon_prices.json`.

## Полезно знать

- **Окно браузера видно специально** — так Ozon реже показывает капчу.
  Если хочешь скрытый режим, поставь в `ozon.py` вверху `HEADLESS = True`
  (но капчи станет больше).
- **Первый запуск** может попросить капчу — реши её прямо в открывшемся
  окне, дальше cookies сохранятся в папке `.ozon_profile` и капча будет
  реже.
- **Частота.** Ozon чувствителен к ботам. Не гоняй чаще **раза в 3–6 часов**
  и не добавляй слишком много товаров за раз. Между товарами скрипт сам
  ждёт 12–25 секунд.
- **Если поймал капчу** во время прохода — скрипт остановится и попросит
  повторить **через 30–60 минут**. Это не «бан навсегда»: у Ozon обычно
  временное ограничение на несколько часов, к следующему дню проходит.
  Смена IP (перезагрузка роутера) часто снимает блокировку сразу.
- Сбор данных против правил магазина — для личного отслеживания пары
  товаров это ок, но держи низкую частоту.
