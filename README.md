# МотоМосква.ДТП — статистика

Telegram Mini App со статистикой мотоаварий по данным канала [@motomskdtp](https://t.me/motomskdtp).
Живёт на GitHub Pages: https://feeltheambience.github.io/motomsk-dtp/

## Что показывает

- лента происшествий по годам (2015 → сейчас) и карта точек
- разбивка по месяцам, типам (мот-авто, мот-мот, одиночное), тяжести
- экипировка, страховка, статус пилота
- отдельные срезы: поломки, розыск, угоны

## Как устроено

Чистая статика, без бэкенда: `index.html` + `app.js` + папка `data/` с готовыми JSON.
Данные собирает бот на сервере и выкладывает сюда, приложение их только читает.

## Запуск локально

Любой статический сервер из корня, например:

    python -m http.server 8000

и открыть http://localhost:8000. Без сервера не заработает — `fetch` данных из `data/` через `file://` браузер режет.
