# drone-vision: тестовая оболочка детекции игроков

Смотрим видео (YouTube-ссылка или файл), YOLO подсвечивает людей,
цвет бокса — по команде (задаётся цветом формы при запуске),
судьи помечаются отдельно. Пауза, перемотка, покадровый просмотр.

## Установка

Нужен Python 3.10+.

```bash
cd drone-vision
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

pip install -r requirements.txt
```

При первом запуске сами скачаются веса модели `yolov8n.pt` (~6 МБ).
ffmpeg не обязателен: с YouTube качается видеодорожка без звука.

## Запуск

Страйкбольный раунд, две команды и судьи в жёлтом:

```bash
python watch.py "https://www.youtube.com/watch?v=jx4aFSTklTA" \
    --team "Зелёные:green" --team "Синие:blue" --ref yellow
```

Пейнтбольный раунд:

```bash
python watch.py "https://www.youtube.com/watch?v=DCZXigdHMmA" \
    --team "Красные:red" --team "Чёрные:black" --ref orange
```

Цвета: `red blue green yellow orange purple white black`
(можно по-русски: `красный синий ...`) или hex `#3050ff`.
Формат команды — `Имя:цвет`, судьи — `--ref цвет`.

Ролик скачивается один раз в папку `video_cache/`, дальше берётся из кэша.

## Управление

| Клавиша | Действие |
|---|---|
| ПРОБЕЛ | пауза / продолжить |
| A / D (или стрелки) | перемотка −5 / +5 сек |
| Z / X | перемотка −30 / +30 сек |
| `.` | шаг на один кадр (в паузе) |
| R | фильтр: все → только судьи → только игроки |
| T | вкл/выкл детекцию (сырое видео) |
| `[` / `]` | медленнее / быстрее |
| Q / ESC | выход |

В шапке окна — счётчик людей по командам и судей.

## Если тормозит (слабый ноут)

```bash
python watch.py <источник> --every 3 --imgsz 480 --max-height 480
```

- `--every 3` — детекция каждого третьего кадра (между ними боксы держатся);
- `--imgsz 480` — меньший вход сети, быстрее, чуть хуже видит мелких;
- `--max-height 480` — скачать ролик в меньшем качестве.

Обратно: на сильной машине `--imgsz 960` заметно лучше цепляет мелкие фигуры.

## Прогон без окна (сервер, пакетная разметка)

```bash
python watch.py <источник> --no-window --save out.mp4
```

Обрабатывает весь ролик и пишет размеченное видео в файл.

## Что важно понимать про качество

- Модель по умолчанию (`yolov8n`, обучена на COCO) хорошо видит людей
  с земли и крупных, хуже — мелкие фигуры с высоты. Для реальных полётов
  плановая замена — модель, дообученная на VisDrone (`--model путь.pt`).
- Команда определяется по доле пикселей цвета формы в верхней части
  бокса, с голосованием по последним кадрам трека — метка не мигает.
  Чёрная/белая форма распознаётся по яркости, цветная — по тону.
  Если обе команды в похожем камуфляже, различить их по цвету нельзя —
  это ограничение физики, а не настройки.
